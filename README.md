# Boardsy

Personalized board games. Boardopolis, Boardsycards, and Wilddeck.

This is a live mock of the storefront (Dawn-shaped layout, cream/terracotta, 2D photo overlay). Checkout is simulated — no payments.

## Stack

TanStack Start, React 19, Tailwind v4. Production build: `npm run build` (Vite + Nitro / Vercel).

## Product

- **Boardopolis** — $150 / 2 for $275 / 3 for $375 / +$100 extra
- **Boardsycards** — custom photo deck from $49
- **Wilddeck** — original party cards from $59

Made to order, typically 2–3 weeks. Proof before print.
